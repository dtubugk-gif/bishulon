# בישולון – ספר המתכונים שלי

אפליקציית מתכונים בעברית (PWA) לאייפון ולאנדרואיד: ייבוא מתכונים מקישור, מצילום או בהקלטה קולית, מצב בישול בשליטה קולית ("הבא", "הקודם", "למטה", "למעלה", "טיימר 10 דקות"), שינוי כמויות לפי מספר מנות, טיימרים, רשימת קניות לפי מחלקות בסופר, תכנון ארוחות שבועי, אלבומים, עוזר שף ושיתוף.

## התקנה באייפון
1. פותחים את הקישור בספארי.
2. כפתור השיתוף ← "הוספה למסך הבית".

## טכני
- HTML/CSS/JS בלי שלב בנייה, מודולים של ES. כל הנתונים נשמרים ב-IndexedDB במכשיר בלבד.
- `sw.js` שומר את האפליקציה לעבודה בלי אינטרנט (בכל שינוי בקבצים – להעלות את `VERSION`).
- ייבוא מקישור דרך r.jina.ai (קורא דפים ציבורי); זיהוי טקסט מתמונה עם Tesseract.js במכשיר; דיבור בעזרת Web Speech API של הדפדפן.
